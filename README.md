## ▶️ How to Run

Make sure you have a C compiler such as **GCC** installed.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/C-Mini-Projects.git
```

Move into the repository:

```bash
cd C-Mini-Projects
```

Compile a project:

```bash
gcc ProjectName.c -o ProjectName
```

Run it on Windows:

```bash
ProjectName.exe
```

For example:

```bash
gcc ExpenseTracker.c -o ExpenseTracker
ExpenseTracker.exe
```
